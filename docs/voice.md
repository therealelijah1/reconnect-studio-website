# Voice and copy guidelines

## Voice
Clear, confident, warm. We sound like a senior designer explaining things to a smart founder.

## Do
- Lead with the outcome for the client ("more qualified leads"), then how.
- Use short sentences and plain words.
- Be specific: numbers, timelines, deliverables.

## Don't
- Use buzzwords ("synergy", "world-class", "cutting-edge").
- Talk about tools before talking about results.
- Write paragraphs longer than three lines on mobile.

## Examples
| Instead of | Write |
| --- | --- |
| We craft world-class digital experiences | We design websites that turn visitors into clients |
| Get in touch | Book a 20-minute discovery call |
