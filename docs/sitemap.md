# Sitemap and page goals

| Page | Goal | Primary CTA |
| --- | --- | --- |
| Home | Explain the offer in five seconds | Book a discovery call |
| Work | Prove quality with 3 to 5 case studies | View case study |
| Services | Package the offer: websites, brand, product | Start a project |
| About | Build trust in the founder and process | Book a call |
| Contact | Remove friction to start a conversation | Send message |

## Conversion notes

- One primary CTA per section.
- Social proof (logos or quotes) sits directly below the hero.
- Every case study ends with a link back to Contact.
